# Packs API

The Packs API enables you to create, configure, and manage agent packs - coordinated teams of AI agents that work together on complex tasks.

## Create Pack

Create a new agent pack with specified agents, skills, and configuration.

```http
POST /packs
```

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| name | string | Yes | Name of the agent pack |
| description | string | No | Description of the pack's purpose |
| agents | array | Yes | List of agent IDs and configurations |
| skills | array | No | List of skills for the pack |
| tools | array | No | List of tools to integrate |
| memory | object | No | Memory configuration |
| behavior | object | No | Behavior and personality settings |
| deployment | object | No | Deployment configuration |

### Example Request

```bash
curl -X POST "https://api.aiworkforce.com/v1/packs" \
  -H "Authorization: Bearer your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Customer Service Team",
    "description": "Handles customer inquiries and support tickets",
    "agents": [
      {
        "id": "customer-support-specialist",
        "role": "Primary Handler",
        "priority": 1,
        "configuration": {
          "personality": "friendly",
          "autonomy": 70
        }
      },
      {
        "id": "technical-triage-agent",
        "role": "Technical Support",
        "priority": 2,
        "configuration": {
          "personality": "professional",
          "autonomy": 60
        }
      }
    ],
    "skills": ["ticket-analysis", "customer-communication", "troubleshooting"],
    "tools": ["zendesk-integration", "knowledge-base"],
    "memory": {
      "type": "shared",
      "retention": "7d"
    },
    "behavior": {
      "coordination": "sequential",
      "handoffCriteria": ["technical-issue", "escalation-required"]
    },
    "deployment": {
      "environment": "production",
      "scaling": {
        "minInstances": 2,
        "maxInstances": 10
      }
    }
  }'
```

## List Packs

Retrieve all packs for your organization with filtering options.

```http
GET /packs
```

### Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| status | string | No | Filter by status (created, deployed, paused, archived) |
| agent | string | No | Filter by agent ID |
| page | integer | No | Page number (default: 1) |
| limit | integer | No | Items per page (default: 20) |
| sort | string | No | Sort by (name, created, updated) |
| order | string | No | Sort order (asc, desc) |

### Example Request

```bash
curl "https://api.aiworkforce.com/v1/packs?status=deployed&page=1&limit=10" \
```

## Update Pack

Update configuration of an existing pack.

```http
PUT /packs/{packId}
```

### Example Request

```bash
curl -X PUT "https://api.aiworkforce.com/v1/packs/pack_abc123" \
  -H "Authorization: Bearer your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Enhanced Customer Service Team",
    "agents": [
      {
        "id": "customer-support-specialist",
        "configuration": {
          "autonomy": 75,
          "intelligence": 7
        }
      }
    ],
    "deployment": {
      "scaling": {
        "minInstances": 3,
        "maxInstances": 15
      }
    }
  }'
```

## Deploy Pack

Deploy a pack to make it active for task execution.

```http
POST /packs/{packId}/deploy
```

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| environment | string | Yes | Deployment environment (staging, production) |
| scaling | object | No | Scaling configuration |
| rollback | boolean | No | Enable automatic rollback on failure |

### Example Request

```bash
curl -X POST "https://api.aiworkforce.com/v1/packs/pack_abc123/deploy" \
  -H "Authorization: Bearer your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "environment": "production",
    "scaling": {
      "minInstances": 2,
      "maxInstances": 10,
      "targetCpuUtilization": 70
    },
    "rollback": true
```

## Test Pack Configuration


|-----------|------|----------|-------------|
| testScenario | string | Yes | Test scenario name |
| input | object | Yes | Test input data |

### Example Request

## Error Codes

| Code | Description | Resolution |
|------|-------------|------------|
| PACK_NOT_FOUND | Pack with specified ID not found | Verify pack ID is correct |
| INVALID_CONFIGURATION | Invalid pack configuration | Check configuration parameters |
| DEPLOYMENT_FAILED | Pack deployment failed | Check deployment settings and logs |
| PACK_ALREADY_DEPLOYED | Pack is already deployed | Use update instead of deploy |
| INSUFFICIENT_PERMISSIONS | Insufficient permissions for operation | Check user permissions |

<Note>
  **Pro Tip**: Always test pack configurations before deploying to production to ensure agents work together effectively.
</Note>
