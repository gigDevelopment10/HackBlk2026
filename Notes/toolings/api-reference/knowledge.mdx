# Knowledge API

The Knowledge API enables you to manage knowledge sources, feed organization-specific data, and query the knowledge base for AI agent context.

## Create Knowledge Source

Create a new knowledge source for feeding data to AI agents.

```http
POST /knowledge/sources
```

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| name | string | Yes | Name of the knowledge source |
| type | string | Yes | Source type (web-scraping, file-upload, documentation, knowledge-base) |
| config | object | Yes | Source-specific configuration |
| processing | object | No | Processing options |
| schedule | object | No | Update schedule |
| metadata | object | No | Additional metadata |

### Example Request

```bash
curl -X POST "https://api.aiworkforce.com/v1/knowledge/sources" \
  -H "Authorization: Bearer your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Company Documentation",
    "type": "documentation",
    "config": {
      "platform": "confluence",
      "url": "https://your-company.atlassian.net/wiki",
      "credentials": {
        "username": "api-user",
        "token": "confluence-api-token"
      },
      "spaces": ["HR", "ENG", "PRODUCT"],
      "filters": {
        "includeArchived": false,
        "dateRange": "last-90-days"
      }
    },
    "processing": {
      "extractImages": true,
      "extractTables": true,
      "extractMetadata": true,
      "ocrEnabled": true
    },
    "schedule": {
      "type": "cron",
      "expression": "0 2 * * *",
      "timezone": "America/New_York"
    },
    "metadata": {
      "department": "all",
      "priority": "high",
      "tags": ["internal", "documentation"]
    }
  }'
```

### Example Response

```json
{
  "success": true,
  "data": {
    "sourceId": "src_abc123",
    "name": "Company Documentation",
    "type": "documentation",

    },
```

## Update Knowledge Source

Update configuration of an existing knowledge source.

```http
PUT /knowledge/sources/{sourceId}
```

### Example Request

```bash
curl -X PUT "https://api.aiworkforce.com/v1/knowledge/sources/src_abc123" \
  -H "Authorization: Bearer your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "schedule": {
      "expression": "0 3 * * *",
      "timezone": "America/New_York"
    },
    "processing": {
      "chunking": {
        "maxChunkSize": 800,
        "overlap": 80
      }
    }
  }'
```

## Process Knowledge Source

Manually trigger processing of a knowledge source.

```http
POST /knowledge/sources/{sourceId}/process
```

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| force | boolean | No | Force reprocessing of all documents |
| filters | object | No | Apply specific filters for this run |

### Example Request

```bash
curl -X POST "https://api.aiworkforce.com/v1/knowledge/sources/src_abc123/process" \
  -H "Authorization: Bearer your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "force": false,
    "filters": {
      "spaces": ["HR"],
      "dateRange": "last-7-days"
    }
  }'
```

### Example Response

```json
{
```

## Query Knowledge Base

Search the knowledge base for relevant information.

```http
POST /knowledge/query
```

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| query | string | Yes | Search query |
| filters | object | No | Filter results |
| limit | integer | No | Maximum results (default: 10) |
| threshold | number | No | Similarity threshold (default: 0.7) |

### Example Request

```bash
curl -X POST "https://api.aiworkforce.com/v1/knowledge/query" \
  -H "Authorization: Bearer your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "What is the company vacation policy?",
    "filters": {
      "sourceIds": ["src_abc123"],
      "categories": ["hr-policy"],
      "dateRange": {
        "start": "2024-01-01",
```

## Upload Documents

Upload documents directly to a knowledge source.

```http
POST /knowledge/sources/{sourceId}/upload
```

### Request Body (multipart/form-data)

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| files | file | Yes | Document files to upload |
| metadata | string | No | JSON metadata for documents |

### Example Request

```bash
curl -X POST "https://api.aiworkforce.com/v1/knowledge/sources/src_abc123/upload" \
  -H "Authorization: Bearer your_api_key_here" \
  -F "files=@document1.pdf" \
  -F "files=@document2.docx" \
  -F 'metadata={"category":"policy","department":"HR"}'
```

## Error Codes

| Code | Description | Resolution |
|------|-------------|------------|
| SOURCE_NOT_FOUND | Knowledge source not found | Verify source ID is correct |
| INVALID_SOURCE_TYPE | Invalid source type specified | Use valid source type |
| PROCESSING_FAILED | Document processing failed | Check document format and size |
| UPLOAD_FAILED | File upload failed | Check file size and format |
| QUERY_FAILED | Knowledge query failed | Check query parameters |
| INSUFFICIENT_PERMISSIONS | Insufficient permissions | Check user permissions |

<Note>
  **Pro Tip**: Use semantic chunking for better knowledge retrieval and set appropriate similarity thresholds to balance precision and recall.
</Note>
