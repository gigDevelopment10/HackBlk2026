# AI Workforce API

The AI Workforce API provides comprehensive access to all platform features, including agent management, pack creation, task execution, and monitoring. This RESTful API enables you to integrate AI agents seamlessly into your applications and workflows.

## Base URL

```
https://api.aiworkforce.com/v1
```

## Authentication

All API requests require authentication using Bearer tokens. Include your API key in the Authorization header:

```bash
Authorization: Bearer your_api_key_here
```

### Getting Your API Key

1. Sign in to your [AI Workforce dashboard](https://dashboard.aiworkforce.com)
2. Navigate to **Settings** → **API Keys**
3. Click **Generate New Key**
4. Copy and securely store your API key

### Security Best Practices

- Never expose your API key in client-side code
- Use environment variables to store API keys
- Implement proper access controls and monitoring
- Rotate API keys regularly

## Rate Limits

API requests are rate-limited to ensure fair usage:

| Plan | Requests per Minute | Requests per Hour | Requests per Day |
|------|-------------------|------------------|------------------|
| Starter | 60 | 1,000 | 10,000 |
| Professional | 300 | 5,000 | 50,000 |
| Enterprise | 1,000 | 20,000 | 200,000 |

Rate limit headers are included in every response:

```bash
X-RateLimit-Limit: 300
X-RateLimit-Remaining: 299
X-RateLimit-Reset: 1640995200
```

## API Versions

The current API version is `v1`. Version information is included in the response headers:

```bash
API-Version: 1.0
```

## Response Format

All API responses follow a consistent JSON format:

### Success Response
```json
{
  "success": true,
  "data": {
    // Response data
  },
  "meta": {
    "timestamp": "2024-01-15T10:30:00Z",
    "requestId": "req_123456789",
    "version": "1.0"
  }
}
```

### Error Response
```json
{
  "success": false,
  "error": {
    "code": "INVALID_REQUEST",
    "message": "Invalid request parameters",
    "details": {
      "field": "teamId",
      "reason": "Required field missing"
    }
  },
  "meta": {
    "timestamp": "2024-01-15T10:30:00Z",
    "requestId": "req_123456789",
    "version": "1.0"
  }
}
```

## HTTP Status Codes

| Code | Meaning | Description |
|------|---------|-------------|
| 200 | OK | Request successful |
| 201 | Created | Resource created successfully |
| 400 | Bad Request | Invalid request parameters |
| 401 | Unauthorized | Invalid or missing API key |
| 403 | Forbidden | Insufficient permissions |
| 404 | Not Found | Resource not found |
| 409 | Conflict | Resource conflict |
| 422 | Unprocessable Entity | Validation failed |
| 429 | Too Many Requests | Rate limit exceeded |
| 500 | Internal Server Error | Server error |

```bash
  "url": "https://your-app.com/webhook",
  "events": ["task.completed", "task.failed"],
  "secret": "whsec_your_secret"
}
```
