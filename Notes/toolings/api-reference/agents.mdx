# Agents API

The Agents API allows you to browse, configure, and manage individual AI agents available in the marketplace.

## List Agents

Retrieve a paginated list of available agents with filtering options.

```http
GET /agents
```

### Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| category | string | No | Filter by agent category (advisory, marketing, technology, etc.) |
| skill | string | No | Filter by specific skill |
| rating | number | No | Minimum rating (1-5) |
| page | integer | No | Page number (default: 1) |
| limit | integer | No | Items per page (default: 20, max: 100) |
| sort | string | No | Sort by (name, rating, usage, created) |
| order | string | No | Sort order (asc, desc) |

### Example Request

```bash
curl "https://api.aiworkforce.com/v1/agents?category=marketing&rating=4&page=1&limit=10" \
  -H "Authorization: Bearer your_api_key_here"
```

## Test Agent

Test an agent with sample input before adding it to a pack.

```http
POST /agents/{agentId}/test
```

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| input | object | Yes | Test input for the agent |
| configuration | object | No | Override default configuration |
| tools | array | No | Enable specific tools for testing |

### Example Request

```bash
curl -X POST "https://api.aiworkforce.com/v1/agents/content-strategist/test" \
  -H "Authorization: Bearer your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "input": {
      "query": "Create a content strategy for a new SaaS product",
      "targetAudience": "B2B software companies",
      "goals": ["lead-generation", "brand-awareness"]
    },
    "configuration": {
      "personality": "creative",
      "responseLength": "detailed"
    },
    "tools": ["google-analytics", "semrush"]
  }'
```

## Search Agents

Search for agents using natural language queries.

```http
POST /agents/search
```

### Request Body

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| query | string | Yes | Natural language search query |
| filters | object | No | Additional filters |
| limit | integer | No | Maximum results (default: 20) |

### Example Request

```bash
curl -X POST "https://api.aiworkforce.com/v1/agents/search" \
  -H "Authorization: Bearer your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "AI agent for financial modeling and risk assessment",
    "filters": {
      "category": "finance",
      "rating": 4.5
    },
    "limit": 10
  }'
```

### Example Response

```json
{
```

## Error Codes

| Code | Description | Resolution |
|------|-------------|------------|
| AGENT_NOT_FOUND | Agent with specified ID not found | Verify agent ID is correct |
| INVALID_CATEGORY | Invalid category filter | Use valid category from /agents/categories |
| TEST_FAILED | Agent test execution failed | Check test input and configuration |
| RATE_LIMIT_EXCEEDED | API rate limit exceeded | Wait before making another request |
| INVALID_QUERY | Invalid search query | Provide valid search parameters |

<Note>
  **Pro Tip**: Use the test endpoint to evaluate agent performance before committing to a paid plan or integration.
</Note>
